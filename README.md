# Agentic AI & LangGraph Course

Learning repository and daily code logs for Agentic AI, LangGraph, and LangChain.

## Structure

- **`LangGraph-agenticAi/`**: Notebooks and scripts building agentic workflows using LangGraph.
- **`langchain course/`**: LangChain foundational exercises, agents, and tooling.
- **`src/`**: Shared code and project modules.

## Setup

1. Copy `.env.example` to `.env` and fill in your API keys:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
